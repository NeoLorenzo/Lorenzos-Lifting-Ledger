# Movement Pattern → Muscle Function Matrix

## Purpose

This matrix is a **functional-anatomy prior**. It identifies which tracked muscle entities are anatomically capable of materially producing each movement pattern.

It is **not** an exercise-to-muscle hypertrophy matrix and should not be used by itself as a hypertrophy-stimulus score.

## Coefficient contract

| Value | Interpretation |
|---:|---|
| 1.0 | Primary / defining producer of the action |
| 0.8–0.9 | Major contributor |
| 0.5–0.7 | Substantial secondary contributor |
| 0.3–0.4 | Meaningful assistant |
| 0.2 | Minor but defensible contributor |
| 0 | Not mapped |

The coefficients are independent, dimensionless functional weights. They are **not percentages or force shares**, and rows must not be normalized.

For isometric movement patterns, the coefficient refers to capacity to generate the named joint torque while joint excursion is negligible.

## Important modelling limits

- A joint action does not uniquely determine force-sharing between synergists.
- Muscle moment arms and force capacity vary with joint angle.
- Biarticular muscles can assist one joint action while opposing another simultaneous joint action.
- Muscles omitted from the canonical taxonomy are not redistributed into tracked muscles.
- The next exercise-specific layer should modify these priors for muscle length, joint position, biarticular interference, support/stabilization, and longitudinal hypertrophy evidence.
